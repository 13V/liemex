Four ways to redraw the Liemex logo

Each keeps the name and "The Solid Timber Specialists". Each is one colour, so it can be cut in vinyl, embroidered, or branded onto a board. These are concepts to react to, not finished artwork.

Where it is now

A badge that's hard to use

  • The globe is a photograph, so it can't be cut, stitched or stamped, and blurs when small.
  • Three lines of text and an outlined name compete for attention.
  • The letters are see-through, so it changes with whatever is behind it.
  • A globe says "import and export". It doesn't say timber.
